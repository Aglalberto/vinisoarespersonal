# Vinicius Soares | Personal Trainer

Landing page estática (HTML + CSS, sem JavaScript) para [@vinisoarespersonal](https://www.instagram.com/vinisoarespersonal/). Todos os CTAs levam ao WhatsApp.

- `index.html`: página com CSS inline
- `img/`: imagens em WebP (versões responsivas) + `og.jpg`
- `fonts/anton-latin.woff2`: fonte dos títulos (Anton, OFL)

## Pendências
- Preencher o CREF (comentado na seção Sobre)
- Revisar os textos marcados com `REVISAR`
- Ao definir o domínio: adicionar `og:url` e usar URL absoluta em `og:image`
